# 📚 Learning Log

## Infrastructure / DevOps Engineering Journey

This repository is my **public engineering journal**, documenting my 12-month transition toward Infrastructure / DevOps Engineering.

My focus is on building practical skills in:

* 🐧 Linux
* 🌐 Networking
* 🐍 Python & Automation
* 🐳 Docker
* 🏗️ Terraform & Infrastructure as Code
* ☁️ Cloud
* 🔄 CI/CD
* 🔐 DevSecOps & Infrastructure Security

Alongside the professional track, I will also document my academic work in **IoT Security**, including my Master's dissertation on lightweight authentication for MQTT-based ESP32 sensor networks.

---

## 🎯 The Goal

The goal of this repository is not simply to record what I study.

It is to document the complete engineering process:

> **Learn → Build → Document → Improve**

Each entry should capture what I learned, what I built, the problems I encountered, how I solved them, and what I would improve.
